# Little Lemon Restaurant

A responsive, single-page restaurant website built with plain HTML and CSS. It was created as a portfolio project to practice semantic HTML and page layout.

**Created by:** Deepak Kumar Sahu

## Features

- Logo header and a sticky navigation bar
- Summer promotion banner (20% discount)
- Restaurant opening hours for each day of the week
- New menu highlights, split into Vegetarian and Non-Vegetarian dishes
- "Book Your Table" section linking to a booking page
- Footer with copyright and author credit
- Responsive layout that adapts to tablets and phones

## Layout

The page follows a basic semantic structure:

```
<header>   Logo
<nav>      Home | Menu | Contact | About
<main>     Promotion, Timing, Menu, Booking
<footer>   Logo, copyright, author
```

## Built With

- HTML5 (semantic tags)
- CSS3 (Flexbox, Grid, CSS variables, animations, media queries)
- Google Fonts: Roboto Mono

1. Download or clone this project.
